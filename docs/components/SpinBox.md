# SpinBox

| layer | decision | why | token or pattern | verified by |
| --- | --- | --- | --- | --- |
| posture | A compact auxiliary control for a practiced user setting one bounded numeric value; not a calculator or free-form expression editor. | Spinbuttons are for discrete bounded values (WAI-ARIA APG); the shell is a learned sovereign tool. | native spinbutton | UX audit: purpose and affordance are immediate |
| task | Show the host's value and let pointer, keyboard, wheel, accessibility actions, or direct text entry request a bounded change. | Qt DoubleSpinBox and the APG converge on one field with decrease/increase actions. | `T.DoubleSpinBox` | every route changes the same value |
| interaction | Decrease is left, increase right; click steps once, hold repeats, Up/Down step, the wheel steps only while the field has focus (an unfocused field hands the wheel to the scroller beneath it; WinUI's NumberBox steps on scroll only while it has focus, https://learn.microsoft.com/en-us/windows/apps/design/controls/number-box, and also takes PageUp and PageDown for a larger step), Home/End move the caret while editable and reach the bounds when typing is off (`toMinimum()`/`toMaximum()` stay available either way), Return or focus loss accepts valid typed text. | Qt template behavior plus APG keyboard contract; focus remains on the field. | `decrease()`, `increase()`, `toMinimum()`, `toMaximum()` | flow `spinbox-pointer-keys` |
| ia | One focusable body contains both indicators and a centred editable reading; labels and error copy remain outside in `Field`. | A spinbutton is one value, not three tab stops; one label element names a control from outside. | content item + two indicators | the Tab walk reaches one stop |
| hierarchy | One quiet `surface` body; hover grows the body by `StateLayer.growth` (whole device pixels a side, bounded by `growthCap`) and lifts its colour, focus lifts it; the reading, caret and indicators stay put, indicator glyphs also grow and press inward, and only a failed host verdict adds a border. | The surface ladder and five-state law reserve borders for semantic facts. | `Surface`, `StateLayer` | rest/hover/press/focus/failed shots |
| token | `size` resolves to `fieldHeight` (Control family: xs 24 / sm 32 / md 40 / lg 48); width is the constant `spinBoxWidth` scaled with the instance; text, glyphs and insets snap to their own scales. A value too long for the fixed viewport shows its head while nobody is typing (losing digits from the right keeps the magnitude); a host with long values widens `naturalWidth`. | One scale per instance; long formatted values scroll inside instead of resizing the control. | `sizes.Control`, `geometry.spinBoxWidth`, `textNear`, `glyphAlone`, `rhythm` | sm/md/lg and long value |
| responsive | RTL mirrors the indicators; locale, decimals, validator, `textFromValue` and `valueFromText` remain Qt's public formatting contract. | Numeric order and formatting are locale facts, not painted literals. | Qt locale and mirroring | not measured |
| state | Rest, hover, press, focus, disabled, editable/typing off, bound-disabled indicators, wrapping, and host-owned failed are designed; disabled roles blend individually. | Every supported state needs an answer; unavailable is not opacity on a composite. | `Style.tone`, `Style.disabled`, danger focus | every property-only state |
| accessibility | The native spinbutton exposes role, value, min and max; `accessibleName` supplies its external name, focus stays on the field, and indicators add no tab stops. | Native semantics first; APG requires one named spinbutton with current value and bounds. | Qt accessibility bridge | not read: the AT-SPI bus is not available in the slot |
| events | `valueModified()` reports accepted text and interactive pointer, wheel and keyboard changes; `stepUp()`, `stepDown()`, `toMinimum()` and `toMaximum()` explicitly report programmatic actions once. A jump to a bound is one native step with wrapping off (two Bindings that give `stepSize` and `wrap` back), so a range of a million steps does not freeze the window. Native `increase()`/`decrease()` alone do not promise a `valueModified()` report. | Qt separates numeric setters from user-value acceptance; callers needing an intent report use the component actions. | `actions` list | tests/units/tst_SpinBox.qml |
| expected | A host answering component actions or native input receives the final bounded value; a later host write remains visible. Typed text is accepted because the content item states the editor's `text`, which is what Qt reads on Return and on focus loss. | Feedback is driven by the explicit value-modified contract, not every numeric setter. | host-owned `value`, native input and component actions | host-binding regression, typed value in the flow |

Not designed: arbitrary-precision numbers, expressions, units with incompatible parsing, an internal label, async validation, PageUp/PageDown. Radix and shadcn expose no dedicated number-input primitive; Material 3 supplies text-field guidance rather than a spinbutton. Caelestia custom JavaScript stepping was rejected in favor of Qt native stepping.

## Measured

Slot at scale 1.25. md 140 x 40 with 40 x 40 indicators (sm 112 x 32 with 32, lg 168 x 48 with 48), glyph centred in its indicator with offset 0, indicators inside the body and 60 px apart, both hit areas 40 x 40 against the 24 floor. Keyboard focus ring: 42 real Tab presses through the workbench chrome reach the one stop. Maximum over 123,456.7 to 1,000,000 in steps of 0.5: 5121 ms of frozen window before, a single step now. A typed 7.5 and Return then Up gives 8.0 (before: 43.0, the typed text was never taken). Wheel over an unfocused field: value unchanged (before: 42.5 became 43).
