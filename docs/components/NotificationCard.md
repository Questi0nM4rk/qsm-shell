# NotificationCard

A person receiving a transient notification can read its source, headline and message, then open the source's current default action or dismiss the notice. The host owns the record, availability and every consequence.

The opt-in row-material inputs described here are a queued design contract for
`../qsm-desktop/openspec/changes/refine-quiet-luminous-desktop`, phase 6. They are
not implemented in the current card. Its default remains boxless.

| layer | decision | why / source | token or pattern | owner-review evidence, when prepared |
| --- | --- | --- | --- | --- |
| posture | Brief, non-modal feedback; arrival never steals focus | Existing popup purpose; desktop notification spec | Existing rollout / capsule hosts | Arrival leaves the foreground application usable |
| task | Read the actual notification, then optionally open its supplied destination | Production-actions spec: useful message before action | App identity + summary + body | Body is visible without hover |
| ia | Keep app identity and summary first; show a two-line body preview beneath them | Client fields are the only trustworthy context | Existing icon slot; `Prose` roles | Missing body shows no invented copy |
| interaction | One listed `activatePrimary()` reports intent only when the host says the current default exists; dismissal stays separate | Shared action route prevents pointer/key divergence and guessing a named action | `StateLayer`, `T.Action`, `primaryActionEnabled`, `primaryTriggered` | Body tap, Enter, Space, accessibility and caller use the same function; absent/retiring actions do nothing |
| hierarchy | Preserve urgency and source identity; caller may opt into a quiet rounded body with explicit padding | Desktop owner's reference-led containment choice; reusable transparent default | `surfaceColor`, `surfaceRadius`, `surfacePadding`, `Surface`; existing text roles | Body contains source, time and preview without implying a new action or read state |
| token | Give the preview one fixed natural height and the expanded body a bounded viewport | Existing 36px token is headline-only; the new composition needs room while stack growth stays bounded | `Style.notificationPreviewHeight`, `Style.notificationBodyViewportHeight`; notification width and existing spacing/type scales | Short and long messages share the same collapsed height; full content scrolls inside the expanded bound |
| responsive | Keep width fixed; wrap body text and scroll only the expanded long body | Popup/capsule have fixed shell width and clipped host geometry | `Style.notificationWidth`; `Flickable` viewport | Full text stays inside both host bodies |
| state | Preserve hover, press, focus and disabled through `StateLayer`; input withdrawal preserves paint and immediately refuses actions | Component laws and stack retirement contract | `StateLayer`, `inputEnabled`, `Style.disabled` | Press is visible without changing row geometry; disabled cards dim semantic text/tick/glyph colours, while informational no-default rows retain full strength |
| polish | Keep current entrance, expansion and swipe movement; optional row material has no border/shadow or separate lifetime | One body per row, no duplicate policy or movement | Existing `Motion` and stack clip | Padding participates in retained extent; input withdrawal never collapses or dims the frozen picture |

states: collapsed preview and expanded full body; hover still reports/expands, drag still arbitrates swipe, pause and frozen-retirement behavior stay host-owned. Urgency still pairs tick glyph and colour.
actions: `dismiss()`, existing `activateAction(id)`, and `activatePrimary()` share their native, keyboard/accessibility and programmatic routes. Popup mode hides named actions; only exact host-enabled default is primary. The card never calls a service, mutates `entry`, or dismisses itself for primary activation.
pointer: `StateLayer` owns the sole left-tap route and hand cursor when primary is available; its drag-threshold tap is cancelled by a swipe, middle-click dismisses, expanded vertical body scrolling does not also expand the card, horizontal dismissal remains available, and wheel not consumed by the viewport passes through. The primary summary exposes pressed feedback without scaling the card or changing fullscreen geometry.
keyboard: the card offers a tab stop and Enter/Space route only when primary is available and its host grants keyboard focus; it never focuses itself on arrival. Production `EdgeScene` grants exclusive keyboard focus only to listed modals and otherwise uses `WlrKeyboardFocus.None`, so this passive popup has no native keyboard route; the existing notification-center shortcut is separate. No production popup key reachability is claimed. Action-row index behavior remains for center consumers.
screen reader: button role/name only when primary is available; otherwise source, summary and body remain readable text. Body action has a clear accessible name; existing named actions retain their own names.
size: fixed `Style.notificationWidth`; collapsed natural size uses `Style.notificationPreviewHeight`; expanded height is bounded by `Style.notificationBodyViewportHeight` plus existing details. Optional `surfacePadding` contributes on both vertical sides and is included before height is frozen. Body text wraps and scrolls, never grows the stack without bound. Source identity is capped to a Style-derived share of the header so summary keeps room; timestamp sits quietly in that same header. `surfaceColor` defaults transparent, `surfacePadding` defaults zero, and `surfaceRadius` follows Style, so existing callers keep their composition.
tokens: notification width, header height, preview height, body viewport height, iconSm, surface radius/padding, space scale, urgency/text roles and Motion. No local colors or measurements. Material does not decide host background, lifetime or dismissal.
motion: existing entrance, expansion, swipe, freeze and reduced-motion behavior only. Body preview does not add another height animation or alter host/render geometry ownership.
expected: the same `activatePrimary()` is the only primary route and reports `primaryTriggered` only when enabled, visible and input-ready. A missing, stale or disabled default never becomes a first-named-action fallback. Long body is fully readable in the bounded expanded viewport; live relative time refreshes at minute intervals. Keyboard action requires a focus-capable host and is not reachable through the current passive production popup. Component reports intent and host owns effects.
not designed: notification lifetime, protocol lookup, application focus/open confirmation, history, grouping, popup dismissal policy or new shell host geometry. Owner judgment of the prepared composition remains pending.
