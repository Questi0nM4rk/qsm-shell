# Segmented

One of N with every option visible, for panel tabs and value choices. `T.TabBar` owns the native tab model, focus and accessibility contract; the host owns `currentIndex` and answers `selected(index)`, which reports intent and fires only on a real change.
options: labels, or objects `{ label, icon, name, badge, disabled }` (`name` speaks for an icon-only option); a rebuilt array of the same length updates the segments in place
states: rest hover(an unpicked segment's pill grows one device pixel a side and lifts) press(recolours only) focus(keyboard-only ring on the picked segment, or the first available while nothing is picked) picked(the thumb: accent at `opacitySelected` over the track, lifted by the card shadow, accent glyph and label, the label one weight heavier so the state needs no colour) unavailable(no pill, glyph and label through Style.disabled) disabled(the bar dims by colour, never opacity)
actions: Previous, Next, First, Last; pointer, arrows (wrapping unless `wrapNavigation` is false), Home, End and the actions share `select()` / `step()` and skip unavailable options; an RTL bar follows the visual arrow direction; modified keys are left alone; the bar is one Tab stop, and `tabNavigation` opts into Tab and Shift+Tab selecting inside one panel's group
size: `size` is a Control preset (xs 24, sm 32, md 40, lg 48, or a consumer's) into `barHeight`; text, glyph, inset and gap scale through the Style helpers, the pad (air round the pill) snaps down to the rhythm (md 8, sm 4), radius, ring gap and outline do not; segments are equal width, a whole number of device pixels, single-line, and elide
hit area: each segment is the bar's full height (40 at md) and the pill paints inside it, so the zone is the visible control; the 4 px between segments and the end pad answer nothing
accessibility: bar `PageTabList`, segment `PageTab` with `Accessible.selected`; the host names the bar; hand cursor over an available segment
motion: the thumb glides on a pointer choice only (Motion.fast, moveEasing: it moves between places it already occupies), a key, an action or a host change answers where the choice already is; the glide is removed under reduced motion; pill and label colours Motion.micro
tokens: barHeight textSm space2 space1 radiusMd opacitySelected cardShadow* accent textMuted
not designed: vertical orientation, scrolling many options, wrapping labels
