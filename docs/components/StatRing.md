# StatRing

A passive output: one fraction bent into a circle, with its reading held in the middle. A bar compares against other bars; a ring reads as one quantity at a glance.
states: none interactive. Rest is the only state; there is no hover, press, focus, selected or disabled. Value clamps to 0..1 and a fraction at or below 0.005 paints no fill arc, so zero reads as none rather than a round-capped dot. The arc eases to a new value over `Motion.fast`; under reduced motion it is placed.
pointer: claims nothing. No MouseArea, HoverHandler, WheelHandler, Keys handler or focus policy; wheel and keyboard pass through to whatever lies beneath.
screen reader: a static readout named "label, reading" (whichever half is set when only one is, empty when neither).
size: `size` names a preset of the StatRing table (sm 64, md 150, lg 240) and resolves `diameter`, which a caller may state instead; the stroke is `Style.stroke(box * Style.ringStrokeRatio)` in whole device pixels and the reading steps with the box (12, 22 and 28 at the three presets) up the type scale to display; the icon is `Style.iconNear` of the reading size. The arc's centreline sits 0.75 strokes inside the box, so the painted ring is the box less a quarter stroke a side and the rim is never cut by the canvas; `Avatar` reads that inset to size its picture.
content: icon, reading and label stack centred in a column as wide as the square inscribed in the ring's hole (even, so it centres on a whole pixel); long reading and label elide on one line and never enlarge the component. The icon is dropped when it would push the stack taller than that square. Measured, the farthest corner of the stack is 25.5, 55.7 and 82.3 px from the centre against hole radii of 28, 65 and 104. Formatting is the caller's: "72%" and "3.4 GB" are the same ring.
shape: startAngle/sweepAngle make the form. Open (-225/270, gap at the bottom) and closed (-90/360) both hold their label inside the circle.
colour: the fill is `primary`, the active part of a track as in `Meter`, never the accent a passive metric has no claim on; the track is `overlay`. Fill on track is 5.19:1, reading on band 13.71:1, label 8.61:1.
tokens: primary fill, overlay track, text icon, Prose reading and metadata roles, the StatRing size table and ringStrokeRatio; no local colors or measurements.
not designed: thresholds (Meter owns them), indeterminate progress (ProgressBar), interaction, dismissal or selection, a no-data form distinct from zero (the host shows its dash as the reading); the host owns the value and never the ring.
