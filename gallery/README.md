# Gallery

The gallery is a browser design playground for qsm-shell. It uses fixed local
data and never represents desktop runtime behavior.

```bash
npm install
npm run dev
```

Open `?component=<id>` to review a component reference. Add `&state=<state>` to
highlight a specific visual state.

Product-shaped scenarios such as `?scenario=panel`, `?scenario=launcher`, and
`?scenario=notifications` are composition sketches. Native QML previews and the
running desktop remain the implementation truth.

Use `npm run build` and `npm run lint` before handing gallery work back.
